2. Local & CI/CD Static Generator

The static HTML website is generated deterministically by build_value_physics_site.py:

  • Ingests deliverables_registry.csv and extracts 60 deliverables.
  • Ingests empirical_calibration_data_22_commodities.csv.
  • Parses CHANGELOG.md and pm_master_log.txt.
  • Gracefully falls back to bundled ./data/*.json in clean environments without downloads.
  • Generates 100% standalone, dependency-free HTML pages ready for local browsing or web hosting.

3. Zero-Maintenance Hosting

Deploy anywhere with zero configuration:

  • GitHub Pages: Push to gh-pages branch via included GitHub Actions workflow.
  • Cloudflare Pages / Netlify: Connect Git repo; build command: python3 build_value_physics_site.py.
  • Local Browser: Open index.html directly in Chrome/Firefox/Safari (all JSON data is embedded for file:// protocol compatibility).
